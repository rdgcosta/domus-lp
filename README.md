# Domus Italínea - Landing Page

Landing page moderna e otimizada para SEO da Domus Italínea, desenvolvida com Next.js 14+.

## 🚀 Tecnologias

- **Next.js 14+** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** (animações)
- **React Hook Form** + **Zod** (formulários)
- **Lucide React** (ícones)

## 📦 Instalação

```bash
npm install
```

## 🏃 Executar em desenvolvimento

```bash
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000)

## 🏗️ Build para produção

```bash
npm run build
npm start
```

## 🎨 Identidade Visual

- **Cor Principal**: Azul Italínea (#164187)
- **Cores de Apoio**: Nude (#FF9C73) e Nude Light (#FFD0B9)
- **Fonte**: Filson Soft
- **Grafismos**: Círculos em outline

## 📝 Estrutura

- `/app` - Páginas e layouts (App Router)
- `/components` - Componentes React
- `/public` - Arquivos estáticos

## 🔍 SEO

- Meta tags otimizadas
- Schema.org (dados estruturados)
- Sitemap automático
- Robots.txt configurado

## 📱 Responsivo

Design mobile-first, totalmente responsivo para todos os dispositivos.
